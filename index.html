Windows 10 Online — Interactive Windows 10 Desktop OS Simulator

Try a faithful Windows 10 operating system directly inside your web browser with zero downloads or installations. Built with pure HTML5, CSS3 Fluent Acrylic design, and Vanilla JavaScript ES Modules.

Included Windows 10 Shell Features

  • Boot sequence, Windows Spotlight Lock Screen, Sign-In with optional PIN, Sleep/Restart/Shut down, and classic BSOD simulation.
  • Interactive Desktop with marquee selection, icon drag-and-drop, inline F2 rename, context menus, and Recycle Bin restore.
  • 3-Column Start Menu with expandable rail, A–Z app jump list, and customizable Live Tiles.
  • Authentic 40px Taskbar with search box and live math evaluation, Task View with Virtual Desktops, window hover previews, jump lists, Action Center, and 6 system tray flyouts (Calendar, Volume, Network, Battery, Language, Overflow).
  • Full Window Manager featuring sharp 0px Windows 10 corners, 8-way resize, Aero Snap left/right/top/quadrants, Alt+Tab switcher, Win+X menu, Run dialog, and Winver.
  • Dark & Light Windows/App theme modes, 32 official accent colors, live brightness slider, Night Light warm filter, and Web Audio API Windows 10 sound effects.

10 Built-In Core Apps

  • File Explorer — Ribbon UI, This PC storage view, breadcrumb bar, Recycle Bin, and full CRUD on a persistent localStorage Virtual File System.
  • Settings — Personalization (wallpapers, 32 accent colors, light/dark themes, taskbar options), System Display/Sound/About, Network, and Accounts.
  • Notepad — Classic Win32 menus, open/save to Virtual File System, Find & Replace, Word Wrap, and Zoom.
  • Calculator — Fluent UWP Standard & Scientific modes, memory registers, and calculation history.
  • Microsoft Edge — Multi-tab Chromium Edge interface with address bar, bookmarks, and navigation history.
  • Command Prompt (cmd.exe) — Interactive terminal connected to the Virtual File System (dir, cd, mkdir, type, echo, cls, ver, color, help, and more).
  • Task Manager — Live processes list with End Task plus real-time animated CPU, Memory, Disk, and Wi-Fi canvas graphs.
  • Paint — Classic mspaint with pencil, brush sizes, eraser, flood fill, shapes, color picker, undo, and PNG save to Pictures.
  • Photos — Gallery viewer with zoom, rotate, and one-click Set as Desktop Wallpaper.
  • Minesweeper — Classic puzzle game with timer, flagging, and difficulty presets.
